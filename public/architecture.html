7. Apply hooks and run permitted tools

Agent SDK → Demo tools. Hooks observe and guard the calls. Only auth.ts edits and exactly npm test are permitted in repair mode.

if (input.hook_event_name !== "PreToolUse") return {};

Demo tools → Agent SDK. Tools return results to the SDK. A failing npm test is useful feedback, not automatically a failed overall run.

10. Send feedback; repeat if needed

Agent SDK → Claude API. The SDK performs the next model interaction itself; the host does not implement a manual Messages API loop.

Source: src/agent.ts · lines 149–151

Selected source excerpt; surrounding context may be omitted.

for await (const message of conversation) {
  for (const event of projector.consume(message)) { if (event.type === "result") gotResult = true; emit(event); }

How this code explains step 10

The same query iterator is consumed while the SDK feeds tool results back to the model and repeats internally. There is no extra application-level call that fabricates this feedback.

Agent SDK → Host observer. The stream yields success or an error subtype with cost/usage/session metadata. Iterate through any trailing events.

if (message.type === "result") {

13. Show trace, outcome and evidence

Host observer → Student. Students compare final SDK status, response grouping, tool IDs, actual changes and independent checks.

Source: src/client.ts · lines 18–26

Selected source excerpt; surrounding context may be omitted.

function workspace(data: any) {
  $(data.stage).textContent = data.source; Prism.highlightElement($(data.stage));
  $(data.stage + "-checks").textContent = `${data.checks.passed}/${data.checks.total} independent checks passed`;
  if (data.stage === "after") {
    $("verdict").textContent = data.checks.passed === data.checks.total && data.changed ? "Verified repair" : options.scenario === "inspect" && !data.changed ? "Read-only inspection: file unchanged" : "Stopped or not repaired";
    $("checks").replaceChildren();
    for (const item of data.checks.cases) { const row = document.createElement("li"); row.textContent = `${item.passed ? "PASS" : "FAIL"} · ${item.label}`; $("checks").append(row); }
  }
}

How this code explains step 13

The workspace handler highlights the actual source and renders each independent check. Verified repair requires changed source and all checks passing; read-only and stopped outcomes stay distinct.
